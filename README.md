# Banalili Resto (no PHP)

Pure HTML / CSS / JavaScript. No server needed.

| Page | File | What it does |
|------|------|--------------|
| Front | `index.html` | Customer enters name + contact |
| Middle | `order.html` | Pick dishes, dine-in/take-out, place order, get code |
| Back | `admin.html` | Staff email login, then history of all orders |

- Edit dishes and prices in `js/menu.js`.
- Orders are saved in the browser (localStorage), so the staff page must be opened in the same browser as the orders.
- Staff login accepts any valid email.

Open `index.html` in Chrome (or use VS Code Live Server).
